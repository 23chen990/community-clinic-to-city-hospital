## 锁定行为

- 今日目标、事件轨道是地图浮层，可展开/收起，不挤压地图。
- 暂停和倍速分开；倍速可切换 0.5x / 1x / 2x。
- 患者摘要只有点击患者后出现。
- 同一时间只显示一个主要上下文面板。
- 卡片按内容自适应，不强制同高。
- 手机横屏复杂面板约占屏幕 70%-80%，不默认全屏。
- 调度执行后回到经营状态，由地图、队列和人员状态表达结果。
- 结算页显示医院状态和科室状态，不重复统计，不显示教学提示。

## 当前实现覆盖规则

- 当前只有 UX-01 和 UX-02 为 `APPROVED`，可以作为实现基线。
- UX-03 与 UX-04 仍为 `UX REVIEW`，不得直接照图实现。
- UX-03 或 UX-04 中出现的“开始晚班”和夜班解锁测试入口均为过时或测试内容，不得直接实现。
- 当前首个纵切的白班结算主按钮固定为“安排下一日”。
- 正式“开始晚班”只在医院升级到社区医院、夜班制度已经解锁后出现。
