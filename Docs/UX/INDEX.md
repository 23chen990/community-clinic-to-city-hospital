## 锁定行为

- 今日目标、事件轨道是地图浮层，可展开/收起，不挤压地图。
- 暂停和倍速分开；倍速可切换 0.5x / 1x / 2x。
- 患者摘要只有点击患者后出现。
- 同一时间只显示一个主要上下文面板。
- 卡片按内容自适应，不强制同高。
- 手机横屏复杂面板约占屏幕 70%-80%，不默认全屏。
- 调度执行后回到经营状态，由地图、队列和人员状态表达结果。
- 结算页显示医院状态和科室状态，不重复统计，不显示教学提示。
