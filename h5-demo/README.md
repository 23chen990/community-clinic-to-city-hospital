# 青禾社区诊所 · H5 经营切片

纯静态 H5 页面，面向平板与手机横屏浏览器。无需安装依赖。

## 启动试玩

在项目目录运行：

```sh
python3 -m http.server 8080 --directory h5-demo
```

然后访问 <http://localhost:8080>。也可以在仓库根目录双击 `启动H5试玩.command`。

## 当前可玩内容

五名患者从接待、分诊、全科初诊进入基础化验或治疗；结果发布后返回全科复诊，再经治疗和药房离院。玩家可暂停、调整倍速、查看地图上的科室状态，并选择风险优先、临时支援或外送样本处理结果积压。所有患者结束后可查看白班结算。

## 验证

```sh
node --test h5-demo/simulation.test.mjs
```

当前这是浏览器可试玩的独立 H5 纵切模型，后续需要与仓库中的纯 C# 模拟核对规则与数值。
